# 2.9 Cerrar caja al finalizar el turno: conteo, reporte y confirmación

Use este procedimiento cuando terminó la operación del turno y las ventas, mesas y pedidos pendientes ya fueron resueltos. El cierre se inicia desde **CAJA**; no es una función exclusiva del rol Supervisor.

## Antes de cerrar

1. Confirme que terminó de registrar cobros y movimientos del turno.
2. Revise que no queden mesas ocupadas ni pedidos Delivery o Calle pendientes. Si el sistema informa un bloqueo, siga [4.11 No puedo cerrar caja](../paquete-4/4.11-no-puedo-cerrar-caja-resolver-mesas-pedidos-y-sesiones-pendientes.md).
3. Ingrese a **CAJA** desde la barra inferior.

## Conteo y revisión

1. Abra la pestaña **CONTEO** y registre el efectivo contado por denominación si el negocio usa este control.
2. Seleccione **Guardar monedas** y espere el mensaje de confirmación. Este botón guarda el conteo y muestra después el reporte actualizado.
3. Abra **CIERRE DE CAJA** y revise ventas, medios de pago, ingresos y egresos mostrados para la sesión.
4. Compare el efectivo físico con el arqueo y, si corresponde, imprima o conserve el reporte según el procedimiento del negocio.

El conteo y la impresión son controles recomendados: el botón **CERRAR CAJA** no los exige como condición técnica.

## Confirmar el cierre

1. En **CIERRE DE CAJA**, seleccione **CERRAR CAJA**.
2. Lea la confirmación: después del cierre no se podrán registrar ventas ni pedidos en esa caja.
3. Confirme únicamente si la revisión del turno está completa.
4. Espere el mensaje de cierre correcto antes de salir de la pantalla.

## Resultado esperado

La sesión de caja queda cerrada. Mientras permanezca en esta pantalla, **CONTEO**, el reporte y **EGRESOS-INGRESOS** siguen asociados a la sesión que acaba de cerrar. El reporte ampliado **R. SUPERVISOR** sólo aparece para administrador, supervisor o cajero cuando la configuración del negocio lo habilita.

Si el equipo opera sin conexión, el cierre también intenta sincronizarse; una falla de sincronización muestra **Reintentar**. Espere una confirmación correcta o resuelva el error antes de salir. El conteo no se guarda por cerrar caja: requiere **Guardar monedas**.

## Si hay una diferencia o una corrección posterior

No cierre para ocultar un descuadre. Documente la diferencia y solicite a la persona responsable autorizada que la revise mediante [7.4 Supervisor: revisar y ajustar caja después del cierre](../paquete-7/7.4-cierre-operativo-rapido-checklist-de-supervisor-antes-de-entregar-caja.md). Para análisis histórico o conciliación, consulte [1.1 Cómo generar el reporte de cierre de caja](../../../panel-administrativo/fichas/paquete-1/1.1-leer-el-reporte-de-cierre-de-caja.md).
